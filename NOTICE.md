# Source and dependency notices

This repository extracts application modules for technical review. Original in-file notices remain in place. No new blanket license grant is introduced by this extraction.

ESP-IDF, FreeRTOS, ESP-SR, XiaoZhi, LN882H SDK and audio codecs are external dependencies. Their source code, precompiled libraries, models, production credentials and media assets are not bundled here. Test doubles implement only the small platform interfaces needed by host tests; they are not replacement SDKs.

Upstream-derived modifications, when present, are represented as focused patches and keep the upstream license notice. Read SOURCE_MANIFEST.json for the file provenance and documented adaptations.
